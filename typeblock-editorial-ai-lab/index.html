JSON template
LOADING — restoring the active local dataset before the layout starts.

Fudebam import reads only entries[]: content, createdAt, and captureOrigin. Records with hiddenAt or mergedIntoEntryID are excluded. Annotations, revisions, and AI review sessions remain sidecars rather than becoming Layout Entries. The newest 10 active Entries are selected, then placed oldest → newest.

The selected 10-entry snapshot, Editorial Analysis, and Editorial Projection are stored locally in this browser. Reopening the same localhost page restores them without another API call when the Entry text and model are unchanged.

The active layout is a Rolling Editorial Index. Consecutive Entries form Lead, Matrix, or Feature bands; source order never changes, similar material shares aligned cells, and every Entry retains its length-derived body territory while title/deck rows are budgeted separately.

The two profiles reuse the same Entry order, Editorial Analysis, area ratios, titles, and decks. Physical gutters, text measure, and band geometry adapt to the active screen.

Editorial index

ROLLING EDITORIAL INDEX — initializing Lead, Matrix, and Feature bands.

The index is the stable overview state: title, deck, and an area-weighted source preview. Clicking a cell goes directly to the full Source Reader; there is no persistent expanded-card middle state.

TYPE V1 — initializing browser text measurement.

Sans body with explicit CJK fallback · 16/24 body · 20/24 dominant · 12/16 caption tokens · standard 400/500/600/700 weights · 4/8 px baseline lock. Text is measured in the active browser font rather than estimated from a fixed average glyph width.

Editorial projection

PROJECTION V1 — original titles are extracted locally; eligible missing titles and decks run only after you click Generate.

Collected Entries ≥600 characters receive title + deck; collected Entries 220–599 receive title only; short authored notes remain unprojected, while long authored Entries may receive a title without a deck. Generated text is a local display sidecar and never rewrites the source.
